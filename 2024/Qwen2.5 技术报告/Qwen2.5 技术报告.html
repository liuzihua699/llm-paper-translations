Qwen2.5 技术报告

论文发布日期2024 年 12 月 19 日

作者： Qwen 团队

模型与代码： Hugging Face · ModelScope · GitHub

摘要

本报告提出 Qwen2.5，一个面向多样需求的完整大语言模型系列。相较上一代，Qwen2.5 在预训练和后训练阶段均显著改进。预训练方面，高质量数据从 7 万亿词元扩展到 18 万亿，为常识、专业知识与推理能力奠定坚实基础。后训练方面，使用超过 100 万条样本进行精细监督微调，并采用多阶段强化学习，包括离线 DPO 与在线 GRPO。后训练显著改善人类偏好对齐，尤其提高长文本生成、结构化数据分析和指令遵循。

为适应多样用例，Qwen2.5 提供丰富配置。开放权重包含 0.5B、1.5B、3B、7B、14B、32B、72B 的基础模型和指令模型，也提供指令模型量化版；Hugging Face、ModelScope 和 Kaggle 上共有超过 100 个模型。托管方案目前包含两个专有混合专家变体 Qwen2.5-Turbo 与 Qwen2.5-Plus，均可通过阿里云百炼使用。

Qwen2.5 在语言理解、推理、数学、代码和人类偏好对齐等广泛基准上达到顶尖水平。开放旗舰 Qwen2.5-72B-Instruct 超过多种开放和专有模型，并能与参数约大五倍的 Llama-3-405B-Instruct 竞争。Qwen2.5-Turbo 与 Plus 成本效益更高，分别可与 GPT-4o-mini、GPT-4o 竞争。Qwen2.5 还作为基础，支持训练 Qwen2.5-Math、Qwen2.5-Coder、QwQ 和多模态模型。

图 1 展示 Qwen 系列迭代中数据扩展的重要作用。使用 18 万亿词元预训练的 Qwen2.5 在系列内能力最强，领域专长尤其突出，说明规模与数据混合共同增强模型能力。

1 引言

随着大型基础模型，尤其大语言模型迅速发展，通用人工智能的火花日益清晰。模型和数据规模持续扩大，再结合大规模预训练、高质量监督微调与人类反馈强化学习，使 LLM 涌现语言理解、生成与推理能力。近期推理时扩展的突破，尤其 o1 所展示的逐步推理与反思，又增强模型深度思考能力。随着更一般人工智能能力不断涌现，语言模型也可能在科学探索中取得重大突破。

除能力快速增长外，过去两年 LLM 社区还涌现大量开放权重大模型，包括 Llama、Mistral 与 Qwen 系列。开放权重让普通用户和开发者更容易使用大模型，使更多人参与研究，通过社区协作促进创新，并加速不同领域人工智能应用开发。

我们发布 Qwen 系列最新版本 Qwen2.5 的详细信息。开放权重部分包含 0.5B、1.5B、3B、7B、14B、32B、72B 七种规模的预训练与指令调优模型，不仅提供 bfloat16 原始模型，也提供不同精度量化模型。旗舰 Qwen2.5-72B-Instruct 能与参数约大五倍的 Llama-3-405B-Instruct 竞争。专有混合专家模型 Qwen2.5-Turbo 与 Plus 则分别对标 GPT-4o-mini 与 GPT-4o。

Qwen2.5 的主要特点如下：

  • 规模更好。 除 Qwen2 已有 0.5B、1.5B、7B、72B 外，重新提供 3B、14B、32B，更适合资源受限场景，并填补当前开放基础模型中这些规模不足的问题。Turbo 与 Plus 在准确率、延迟和成本间提供良好平衡。
  • 数据更好。 预训练与后训练数据显著改善。预训练从 7 万亿增至 18 万亿词元，重点加强知识、代码和数学，并分阶段调整数据混合。后训练数据超过 100 万条，贯穿 SFT、DPO 和 GRPO。
  • 使用更好。 解决 Qwen2 的多项限制，包括把生成长度从 2000 提高到 8000 词元，更好支持表格、JSON 等结构化输入输出，并更易调用工具。Qwen2.5-Turbo 上下文最长达到 100 万词元。

2 架构与词元化器

Qwen2.5 系列包含用于开放发布的稠密模型 0.5B、1.5B、3B、7B、14B、32B、72B，以及用于 API 服务的混合专家模型 Turbo 与 Plus。

稠密模型延续 Qwen2 的 Transformer 仅解码器架构，集成分组查询注意力以高效使用键值缓存、SwiGLU 非线性激活、旋转位置嵌入、注意力中的 QKV 偏置，以及采用预归一化的 RMSNorm 以稳定训练。

在稠密架构基础上扩展混合专家：把标准前馈网络替换为专用 MoE 层，每层含多个前馈专家与路由机制，把词元分派给前 $K$ 个专家。沿用 Qwen1.5-MoE，采用细粒度专家分割和共享专家路由，显著改善下游任务性能。

词元化使用 Qwen 的字节级字节对编码，常规词表含 151643 个词元。与早期 Qwen 相比，控制词元从 3 个增至 22 个，其中两个用于工具功能，其余预留给其他能力。全部 Qwen2.5 共用统一词表，提高一致性并减少兼容问题。

表 1 给出开放模型架构与许可证。0.5B、1.5B、3B 上下文为 32K、生成长度 8K；7B 以上支持 128K 上下文、8K 生成。多数模型采用 Apache 2.0，3B 与 72B 使用相应 Qwen 许可证。

3 预训练

预训练包含几个关键部分：通过复杂过滤、评分和数据混合整理高质量数据；广泛研究超参数优化，以有效训练不同规模模型；最后加入专门长上下文预训练，提高处理长序列的能力。

3.1 预训练数据

Qwen2.5 相较 Qwen2 显著提高数据质量，主要来自四方面。

  1. 更好的数据过滤。 高质量数据决定模型表现。我们用 Qwen2-Instruct 作为质量过滤器，对样本执行全面、多维分析并评分。相较 Qwen2 的过滤方式，新方法受益于 Qwen2 在更大多语言语料上的预训练，能更细致评估质量，在多种语言中既更好保留高质量数据，也更有效删除低质量样本。
  2. 更好的数学与代码数据。 预训练加入 Qwen2.5-Math 与 Qwen2.5-Coder 数据。这些高质量领域数据对数学和代码最先进表现至关重要，使 Qwen2.5 继承强数学推理与代码生成能力。
  3. 更好的合成数据。 使用 Qwen2-72B-Instruct 与 Qwen2-Math-72B-Instruct，在数学、代码和知识领域生成高质量合成数据，再由专有通用奖励模型和 Qwen2-Math-RM-72B 严格过滤。

  1. 更好的数据混合。 使用 Qwen2-Instruct 对不同领域内容分类并平衡。分析发现，网页规模数据中电商、社交媒体和娱乐明显过多，且常含重复、模板化或机器生成内容；技术、科学、学术研究等领域信息质量更高却往往不足。通过下采样过度代表领域、上采样高价值领域，构建更均衡、信息更丰富的数据分布。

利用这些技术，预训练数据由 Qwen2 的 7 万亿扩展到 18 万亿词元，且质量更高。

3.2 超参数缩放定律

我们基于 Qwen2.5 预训练数据建立超参数缩放定律。以往研究主要用缩放定律在给定计算预算下确定最优模型规模；本文则用它跨不同架构寻找最优超参数，尤其为不同规模稠密与 MoE 模型确定批大小 $B$ 和学习率 $\mu$。

通过大量实验，系统研究模型架构与最优训练超参数的关系，分析最优学习率 $\mu_{\mathrm{opt}}$、最优批大小 $B_{\mathrm{opt}}$ 如何随模型规模 $N$ 和预训练数据量 $D$ 变化。实验覆盖 4400 万至 140 亿参数的稠密模型、激活参数 4400 万至 10 亿的 MoE 模型，以及 8 亿至 6000 亿词元的数据集。随后使用预测出的最优超参数，把最终损失建模为模型架构和训练数据规模的函数。

此外，通过缩放定律预测并比较不同参数规模 MoE 与稠密模型的性能，指导 MoE 超参数配置。仔细调整激活参数和总参数后，使 MoE 模型达到 Qwen2.5-72B、14B 等特定稠密变体的性能水平。

3.3 长上下文预训练

为提高训练效率，Qwen2.5 采用两阶段预训练：先以 4096 词元上下文训练，再扩展长序列。除 Turbo 外，全部变体在最终阶段从 4096 扩到 32768，并用 ABF 把 RoPE 基频从 10000 提高到 1000000。

Turbo 使用渐进上下文扩展，依次训练 32768、65536、131072、262144 词元，RoPE 基频设为 10000000。每阶段数据中 40% 序列达到当前最大长度，60% 为较短序列。这让模型平滑适应增长的上下文，同时维持处理不同长度序列的能力。

推理时采用 YARN 与双块注意力，把序列容量提高四倍，使 Turbo 最多处理 100 万词元，其他模型最多 131072。两种技术降低长序列困惑度，也保持短序列表现。

4 后训练

Qwen2.5 相较 Qwen2 有两项重要后训练升级：扩大 SFT 数据覆盖，以及两阶段强化学习。

  1. 扩大监督微调覆盖。 数百万高质量示例专门弥补上一代在长序列生成、数学解题、代码、指令遵循、结构化数据理解、逻辑推理、跨语言迁移和稳健系统指令上的不足。
  2. 两阶段强化学习。 分为离线与在线： - 离线强化学习。 聚焦奖励模型难以评估的推理、事实性和指令遵循。通过严谨构建与验证，确保信号可学习、可靠，使模型有效掌握复杂技能。 - 在线强化学习。 利用奖励模型识别真实性、有帮助程度、简洁性、相关性、无害性和去偏等细微质量，使回答精确、连贯、结构良好，同时保持安全与可读，符合人类质量标准。

4.1 监督微调

SFT 阶段的关键改进包括：

  1. 长序列生成。 输出最长 8192 词元，远超常见后训练不足 2000 词元的回答。我们构建长回答数据集，对预训练语料中的长文本使用回译生成查询，施加输出长度约束，并由 Qwen2 过滤低质量配对。
  2. 数学。 加入 Qwen2.5-Math 思维链数据，来源包括公共数据、K-12 题集和合成问题。结合拒绝采样、奖励建模和标注答案，产生高质量逐步推理。
  3. 代码。 加入 Qwen2.5-Coder 指令数据。多个语言专用智能体协作，在近 40 种编程语言上生成多样、高质量指令对。再从代码问答网站合成新样本，并从 GitHub 收集算法代码片段。多语言沙箱执行静态检查和自动单元测试，确保质量与正确性。
  4. 指令遵循。 建立严格的代码验证框架。LLM 同时生成指令、验证代码和完整单元测试进行交叉验证，再根据执行反馈拒绝采样，保证 SFT 数据忠实遵循目标指令。
  5. 结构化数据理解。 构建完整数据集，覆盖表格问答、事实验证、纠错、结构理解等传统任务，以及结构化、半结构化复杂任务。回答中加入推理链，显著提高从结构数据推断信息的能力。
  6. 逻辑推理。 新增 7 万条覆盖不同领域的查询，包括选择、判断和开放题。训练模型系统地使用演绎、归纳概括、类比、因果和统计推理。迭代过滤错误答案与错误推理，逐步增强准确、稳健逻辑推理。

  1. 跨语言迁移。 用翻译模型把高资源语言指令转换为多种低资源语言并生成回答候选，再评估多语言回答与原回答的语义对齐，保留原回答逻辑结构与风格细节，维持跨语言完整性和连贯性。
  2. 稳健系统指令。 构建数百条通用系统提示，提高后训练系统提示多样性，并确保它们与对话一致。不同系统提示评测中，模型表现良好且方差降低，说明稳健性提高。
  3. 回答过滤。 使用专用评论家模型和多智能体协作评分等多种自动标注。回答经严格评估，只有被全部评分系统判定无缺陷的结果才保留。

最终构建超过 100 万条 SFT 示例。模型以 32768 词元序列长度微调两个轮次，学习率从 $7\times10^{-6}$ 逐步降到 $7\times10^{-7}$；权重衰减 0.1，梯度范数最大裁剪为 1.0。

4.2 离线强化学习

相较在线强化学习，离线强化学习可以预先准备训练信号，特别适合存在标准答案、却难以由奖励模型准确评价的任务。本文聚焦数学、代码、指令遵循和逻辑推理等客观查询领域。

上一阶段已经广泛使用执行反馈和答案匹配保证回答质量；本阶段复用该流水线，让 SFT 模型为新查询重新采样。通过质量检查的回答作为正例，失败者作为负例，用于 DPO。人类与自动审查共同提高信号可靠性和准确性，使数据既可学习又符合人类预期。最终数据约 15 万对，模型使用在线合并优化器训练一个轮次，学习率为 $7\times10^{-7}$。

4.3 在线强化学习

为构建稳健奖励模型，我们制定明确标注准则，使回答既高质量又符合伦理和用户需求：

  • 真实性。 回答基于事实，忠实反映上下文与指令，不生成虚假或无数据支持的信息。
  • 有帮助。 有效解决用户问题，内容积极、有吸引力、有教育意义且相关，精确遵循指令并提供价值。
  • 简洁。 直接、凝练，避免不必要冗长，以清楚高效传达信息。
  • 相关。 回答所有部分都直接关联查询、对话历史和助手上下文，并与用户需求完全对齐。
  • 无害。 优先保证用户安全，避免可能导致违法、不道德或有害行为的内容，始终倡导负责任交流。

  • 去偏。 回答不应包含性别、种族、国籍、政治等偏见，对所有主题公平处理，遵循广泛接受的道德与伦理标准。

奖励模型查询来自公共开源数据和复杂度更高的专有查询集。回答由不同训练阶段、分别经过 SFT、DPO、RL 的 Qwen 检查点生成，并以不同温度采样增加多样性。偏好对由人工与自动标注共同建立，同时合入 DPO 数据。

在线强化学习使用 GRPO。训练奖励模型与 RL 使用相同查询集，查询处理顺序由奖励模型给出的回答分数方差决定，高方差查询优先，以提高学习效果。每个查询采样 8 个回答。全部模型全局批大小为 2048，每轮 2048 个样本，每个查询—回答对视为一个样本。

4.4 长上下文微调

为进一步扩展 Turbo 上下文，后训练加入更长 SFT 示例，使模型在长查询上更符合人类偏好。

SFT 分两阶段。第一阶段只用不超过 32768 词元的短指令微调，数据和步数与其他 Qwen2.5 相同，保证短任务性能；第二阶段混合最多 32768 的短指令与最多 262144 的长指令，提高长上下文指令遵循，同时保持短任务性能。

强化学习只使用短指令，原因是长上下文 RL 计算昂贵，而且缺少适合长任务的奖励模型。实验发现，仅在短指令上执行 RL，仍能显著提高长上下文任务的人类偏好对齐。

5 评测

预训练得到的基础模型与后训练得到的指令模型分别使用完整评测套件测试，既含常用开放基准，也含面向技能的内部数据集，并以自动评测为主、尽量减少人工参与。

为防止测试泄漏，构建训练集时用 n 元语法匹配删除可能污染数据。沿用 Qwen2 标准：若训练序列与某测试序列词元化后的最长公共子序列长度至少为 13，且至少占两者较短者的 60%，就删除该训练序列。

5.1 基础模型

基础模型评测重点覆盖自然语言理解、通用问答、代码、数学、科学知识、推理和多语言能力。通用任务包括 MMLU、MMLU-Pro、MMLU-redux、BBH、ARC-C、TruthfulQA、Winogrande 与 HellaSwag。

数学与科学包括 GPQA、TheoremQA、GSM8K、MATH；代码包括 HumanEval、HumanEval+、MBPP、MBPP+ 与 MultiPL-E；多语言分考试、理解、数学、翻译四类，覆盖 M3Exam、IndoMMLU、ruMMLU、翻译版 MMLU、BELEBELE、XCOPA、XWinograd、XStoryCloze、PAWS-X、MGSM 与 Flores-101。

Qwen2.5-72B 与 Qwen2.5-Plus。 表 2 与 Llama-3-70B、Llama-3-405B、Mixtral-8x22B、Qwen2-72B 比较。Qwen2.5-72B 在同类基础模型中跨广泛任务显著领先，以五分之一参数达到接近 Llama-3-405B 的结果；相较 Qwen2-72B，在几乎全部基准上明显进步，通用、数学和代码尤为突出。

Qwen2.5-Plus 的训练与推理成本显著更低，却能与 Qwen2.5-72B 和 Llama-3-405B 高度竞争，并在 HellaSwag、TheoremQA、MATH、GSM8K、MultiPL-E、多语言数学与翻译上超过其他基线。它在 MMLU-Pro 达到 64.0，比 Qwen2.5-72B 高 5.9 分。

由于奖励模型评测方法匮乏，当前通常只使用 Reward Bench。然而，多种奖励模型基准的结果表明，对单一基准过度优化可能触发古德哈特定律，导致其他基准表现下降，并可能损害下游对齐效果。因此，奖励模型需要跨多种基准进行综合评估，不能只依赖单一基准。

更重要的是，反复实验还揭示了一个关键局限：现有奖励模型评测基准不能准确预测由该奖励模型指导训练出的强化学习模型表现。换言之，奖励模型在基准上得分更高，并不必然意味着最终强化学习模型更强。这说明还需研究对奖励模型更具预测力的评测方法。

6 结论

Qwen2.5 是大型语言模型的一次重大进步：它在 18 万亿词元上强化预训练，并采用监督微调和多阶段强化学习等复杂后训练技术。这些改进增强了人类偏好对齐、长文本生成和结构化数据分析能力，使 Qwen2.5 能够高效完成指令遵循任务。Qwen2.5 提供多种配置，既有参数从 0.5B 到 72B 的开放权重模型，也有专有模型，其中包括 Qwen2.5-Turbo、Qwen2.5-Plus 等高性价比 MoE 变体。实证评测表明，Qwen2.5-72B-Instruct 的表现可与最先进的 Llama-3-405B-Instruct 相当，而参数规模只有后者的六分之一。Qwen2.5 还是多个专用模型的基础，展现出面向领域应用的通用性。我们相信，Qwen2.5 稳健的表现、灵活的架构和广泛可用性，使其成为学术研究与工业应用的重要资源，并将在未来创新中发挥关键作用。

未来，我们将着力推进稳健的基础模型。第一，通过纳入范围更广、更多样且质量更高的数据，迭代改进基础模型和指令微调大型语言模型。第二，继续开发多模态模型，目标是把不同模态整合到统一框架中，实现文本、视觉和听觉领域无缝的端到端信息处理。第三，通过有策略地扩展推理计算资源，增强模型的推理能力。这些工作旨在突破现有技术边界，并为更广泛的人工智能领域作出贡献。
