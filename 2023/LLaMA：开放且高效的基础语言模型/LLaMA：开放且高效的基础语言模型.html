LLaMA：开放且高效的基础语言模型

论文发布日期2023 年 2 月 27 日

作者： Hugo Touvron、Thibaut Lavril、Gautier Izacard、Xavier Martinet、Marie-Anne Lachaux、Timothée Lacroix、Baptiste Rozière、Naman Goyal、Eric Hambro、Faisal Azhar、Aurélien Rodriguez、Armand Joulin、Edouard Grave、Guillaume Lample
机构： Meta AI
论文版本： arXiv:2302.13971v1，2023 年 2 月 27 日

摘要

本文介绍 LLaMA，一组参数规模从 70 亿到 650 亿的基础语言模型。作者在数万亿词元上训练模型，并证明只使用公开可获得的数据集，也可以训练出接近当前最佳水平的模型，而不依赖专有或无法访问的数据。LLaMA-13B 在大多数基准上超过 1750 亿参数的 GPT-3，LLaMA-65B 与 Chinchilla-70B 和 PaLM-540B 等最佳模型具有竞争力。作者公开全部模型，希望降低大语言模型研究和使用的门槛。

1 引言

在海量文本语料上训练的大型语言模型，能够根据文字指令或少量示例执行新任务。模型规模扩大后首先出现了这种少样本能力，随后大量研究继续扩展模型规模。传统假设是参数越多性能越好，但 Chinchilla 的缩放研究表明，在固定计算预算下，最优性能不一定来自最大的模型，而可能来自用更多数据训练的较小模型。

缩放规律通常优化训练计算，却忽略部署和推理预算。实际服务时，给定目标性能，首选模型不是训练最快的模型，而是推理最快的模型；尽管大模型可能更快达到目标，较小模型如果训练更久，部署成本通常更低。例如，Chinchilla 规律建议用 2000 亿词元训练 100 亿参数模型，但作者发现 70 亿参数模型在训练超过 1 万亿词元后仍持续提升。

本文的目标是在不同推理预算下取得尽可能高的性能。LLaMA 系列包含 7B、13B、33B 和 65B 四个模型，均使用公开数据训练。LLaMA-13B 只有 GPT-3 的十分之一大小，却在大多数基准上超过 GPT-3；LLaMA-65B 与 Chinchilla 和 PaLM-540B 具有竞争力。与 Chinchilla、PaLM 和 GPT-3 不同，LLaMA 完全使用公开数据，使模型可以开放发布，也便于复现和研究。作者希望小模型可以在单张 GPU 上运行，从而推动大模型研究民主化。

2 方法

训练方法与此前大型语言模型相似：使用标准优化器，在大量文本上训练 Transformer，并参考 Chinchilla 缩放规律。

2.1 预训练数据

训练语料混合了多个公开来源，总计约 1.4 万亿词元。主要数据和采样比例如下：

数据集 采样比例 主要处理
英文 CommonCrawl 67.0% CCNet 去重、语言识别、质量过滤
C4 15.0% 去重、语言识别和启发式质量过滤
GitHub 4.5% 许可证筛选、文件清洗和完全去重
Wikipedia 4.5% 2022 年 6--8 月的 20 种拉丁/西里尔文字语言
Gutenberg 与 Books3 4.5% 公版书籍和 The Pile 的书籍，按书去重
arXiv 2.5% 清洗 LaTeX，移除导言、注释和参考文献
Stack Exchange 2.0% 选择 28 个最大站点，按回答得分排序

英文 CommonCrawl。 作者使用 2017--2020 年的五个 CommonCrawl 快照，通过 CCNet 按行去重，使用 fastText 线性分类器移除非英文页面，并用 (n)-gram 语言模型过滤低质量内容。另训练线性分类器识别可能被 Wikipedia 引用的页面，丢弃不属于引用页面的内容。

C4。 预实验显示，多样化的网页预处理方式能提升性能，因此加入公开 C4。C4 同样进行去重和语言识别，但质量过滤主要依据页面是否包含标点、词语和句子等启发式指标。

GitHub。 只保留 Apache、BSD 和 MIT 许可证项目。文件按行长度、字母数字比例等规则过滤，用正则表达式删除文件头等样板内容，最后按文件完全去重。

Wikipedia。 加入 2022 年 6--8 月的 Wikipedia 快照，覆盖 20 种使用拉丁或西里尔文字的语言，并清除超链接、评论和格式样板。

书籍。 Gutenberg 项目提供公共领域书籍，Books3 来自公开的 The Pile。按书籍去重，删除内容重叠超过 90% 的书。

arXiv。 处理 arXiv 的 LaTeX 文件以加入科学内容，移除第一节之前的内容和参考文献，删除注释，并把用户定义的宏和定义展开，以提高论文之间的一致性。

Stack Exchange。 加入覆盖计算机科学、化学等领域的高质量问答，保留 28 个最大网站，删除 HTML 标签，并按回答得分从高到低排列。

分词器。 使用 SentencePiece 实现的字节对编码（BPE）算法。所有数字都切分为单独数字；未知 UTF-8 字符回退到字节级分解。Wikipedia 和书籍数据大约重复使用两次，其他数据大多只使用一次。

2.2 架构

LLaMA 基于 Transformer，并采用后续研究提出的三项改进：

  1. 预归一化。 参考 GPT-3，在每个 Transformer 子层的输入而不是输出上做归一化，以提高训练稳定性；归一化函数使用 RMSNorm。
  2. SwiGLU 激活。 参考 PaLM，用 SwiGLU 替代 ReLU，以改善性能。前馈层隐藏维度设为 ( rac{2}{3} imes4d)，而不是 PaLM 使用的 (4d)。
  3. 旋转位置嵌入。 参考 GPT-Neo，移除绝对位置嵌入，在网络每一层加入 RoPE。
模型 参数量 隐藏维度 注意力头 层数 学习率 批大小 训练词元
LLaMA-7B 6.7B 4096 32 32 3.0e-4 4M 1.0T
LLaMA-13B 13.0B 5120 40 40 3.0e-4 4M 1.0T
LLaMA-33B 32.5B 6656 52 60 1.5e-4 4M 1.4T
LLaMA-65B 65.2B 8192 64 80 1.5e-4 4M 1.4T

2.3 优化器

模型使用 AdamW，(β_1=0.9,β_2=0.95)。学习率采用余弦计划，最终学习率为最大值的 10%；权重衰减为 0.1，梯度裁剪值为 1.0，预热 2000 步。模型越大，学习率和批大小会相应调整。

2.4 高效实现

作者使用高效的因果多头注意力实现，减少内存和运行时间。该实现不保存注意力权重，也不计算因果掩码已经屏蔽的键—查询分数。反向传播时使用检查点，只保存计算昂贵的激活，例如线性层输出，并手动实现 Transformer 层的反向函数。

模型并行和序列并行进一步降低内存；GPU 之间的通信与激活计算尽可能重叠。训练 650 亿参数模型时，在 2048 张 A100 80GB GPU 上约达到每 GPU 每秒 380 个词元，训练 1.4 万亿词元大约需要 21 天。

3 主要结果

作者遵循 GPT-3 的零样本和少样本设置，在总计 20 个基准上评测 LLaMA。零样本提供任务文字描述和一个测试示例；少样本提供 1--64 个示例及一个测试示例。模型要么开放生成答案，要么对候选答案排序。比较对象包括 GPT-3、Gopher、Chinchilla、PaLM、OPT、GPT-J 和 GPT-Neo 等基础模型，并在后文简要比较指令微调模型。

3.1 常识推理

作者评估 BoolQ、PIQA、SIQA、HellaSwag、WinoGrande、ARC-easy、ARC-challenge 和 OpenBookQA。LLaMA-65B 在除 BoolQ 外的所有报告任务上超过 Chinchilla-70B，在除 BoolQ 和 WinoGrande 外的任务上超过 PaLM-540B。LLaMA-13B 虽然小十倍，仍在大多数任务上超过 GPT-3。

3.2 闭卷问答

在 Natural Questions 和 TriviaQA 上进行闭卷问答，即模型不能访问包含证据的文档。LLaMA-65B 在零样本和少样本设置下都取得当时最佳或接近最佳的精确匹配表现；LLaMA-13B 与 GPT-3 和 Chinchilla 相当，但推理时可以在单张 V100 GPU 上运行。

3.3 阅读理解

RACE 是从面向初高中学生的英语阅读考试中收集的理解数据集。作者遵循 GPT-3 的评测设置。LLaMA-65B 的零样本准确率与 PaLM-540B 竞争，LLaMA-13B 比 GPT-3 高出几个百分点。

3.4 数学推理

MATH 包含 1.2 万道以 LaTeX 编写的中学和高中数学题，GSM8K 包含中学数学文字题。作者与 PaLM 和在 arXiv/数学网页上继续微调的 Minerva 比较，并报告单次采样及多数投票。LLaMA 没有在数学数据上微调，但 LLaMA-65B 在 GSM8K 上超过 Minerva-62B；使用多数投票后，各规模的数学性能进一步提高。

3.5 代码生成

HumanEval 和 MBPP 要求模型根据自然语言描述生成 Python 程序。HumanEval 还提供函数签名，提示中包含描述和测试。LLaMA 与 PaLM 训练时使用相近数量的代码词元；在相同规模下，LLaMA 优于未专门针对代码训练的 LaMDA 和 PaLM。LLaMA-13B 在 HumanEval 和 MBPP 上超过 137B 的 LaMDA，LLaMA-65B 也超过 PaLM-62B。

代码专用微调仍能带来更大提升，例如 PaLM-Coder 把 PaLM 的 HumanEval pass@1 从 26.2% 提高到 36%。本文不研究代码词元微调。pass@1 使用温度 0.1，pass@100 和 pass@80 使用温度 0.8，并用无偏估计计算 pass@k。

3.6 大规模多任务语言理解

MMLU 覆盖人文、STEM、社会科学和其他知识领域的多项选择题。作者使用基准提供的五个示例。LLaMA-65B 平均准确率落后 Chinchilla-70B 和 PaLM-540B 几个百分点，且在多数领域都落后。可能原因是 LLaMA 使用的书籍和学术论文较少：arXiv、Gutenberg 和 Books3 总计只有约 177GB，而其他模型最多使用 2TB 书籍。

训练过程中，大多数问答和常识任务的性能稳步提升，并与训练困惑度相关；SIQA 波动较大，WinoGrande 与困惑度的相关性较弱，说明部分基准可能不够稳定。

3.7 训练过程中的性能变化

作者在训练期间持续跟踪问答和常识基准。LLaMA-7B、13B、33B 和 65B 的训练损失持续下降，TriviaQA、HellaSwag、Natural Questions 和 PIQA 等任务通常随训练词元增加而提升；SIQA 和 WinoGrande 的变化更不稳定。

4 指令微调

少量指令数据微调就能快速改善 MMLU。LLaMA-65B 的基础版本已经能遵循简单指令，但微调后遵循指令和 MMLU 性能进一步提高。作者按照 Flan 的协议进行一次实验，得到 LLaMA-I。LLaMA-I 在 MMLU 上达到 68.9%，超过中等规模的 OPT-IML 和 Flan-PaLM 模型，但仍低于当时 GPT code-davinci-002 的 77.4%。

5 偏差、毒性和错误信息

网页数据可能包含和放大偏差，也可能生成有毒或冒犯内容。因此作者使用 RealToxicityPrompts、CrowS-Pairs、WinoGender 和 TruthfulQA 评估 LLaMA-65B 的风险。作者强调，这些基准不能覆盖模型全部风险。

5.1 RealToxicityPrompts

RealToxicityPrompts 包含约 10 万条提示，模型需要补全提示，Perspective API 自动给生成文本计算毒性分数。作者对每条提示贪心生成并分别评估普通提示和“以礼貌、尊重、不偏见的方式完成句子”的提示。LLaMA 得分与文献中的模型大体相当，但第三方 API、采样方式和提示数量存在差异，不能简单横向比较。作者观察到毒性通常随模型规模增大而上升，尤其是在尊重式提示上。

5.2 CrowS-Pairs

CrowS-Pairs 用九类偏差的刻板句和反刻板句组成最小句对：性别、宗教、族裔/肤色、性取向、年龄、国籍、残障、外貌和社会经济地位。作者比较模型对两句话的困惑度偏好，偏好刻板句的比例越高，表示偏差越强。

LLaMA-65B 的平均偏差略低于 GPT-3 和 OPT-175B，但宗教类别比 OPT 高约 10%，年龄和性别也比较突出。作者认为，多步 CommonCrawl 过滤仍无法完全去除来源语料中的社会偏见。

5.3 WinoGender

WinoGender 测试模型能否根据句子上下文解决职业和代词的共指关系。句子包含职业、参与者和代词，模型需要判断代词指向谁。LLaMA 在 their/them/someone 上明显优于 her/her/she 和 his/him/he，这可能意味着模型依靠职业的多数性别而不是句子证据解决共指。对“陷阱”样例（代词性别与职业多数性别相反），性能明显下降，显示职业和性别的社会偏见仍被模型捕获。

5.4 TruthfulQA

TruthfulQA 测量模型识别真实世界陈述的能力，问题覆盖 38 个类别并具有对抗性。LLaMA 相比 GPT-3 在“真实”和“真实且有信息”两个指标上都更高，但绝对正确率仍然偏低，说明模型仍可能生成幻觉和错误答案。

6 碳足迹

作者估计训练不同模型所需的总能耗和碳排放，并假设所有模型在同一数据中心训练。耗电量按照 GPU 小时、GPU 功耗和数据中心电能使用效率（PUE）计算；碳排放使用美国全国平均碳强度 0.385 kg CO₂e/kWh。

7 相关工作

语言模型把词、词元或字符序列建模为概率分布。早期方法使用 (n)-gram 统计和各种平滑技术；随后出现前馈网络、循环网络和 LSTM。Transformer 依靠自注意力改善长距离依赖建模，推动 BERT、GPT-2、Megatron-LM、T5、GPT-3、Jurassic-1、Gopher、Chinchilla、PaLM、OPT 和 GLM 等模型发展。

语言模型缩放研究从统计 (n)-gram 延伸到神经 Transformer，揭示模型规模、数据规模与性能之间的幂律关系；Chinchilla 进一步调整数据和模型的比例，LLaMA 则研究在较小模型上使用更多公开数据的效果。

8 结论

本文介绍了 LLaMA 系列开放基础模型。LLaMA-13B 超过 GPT-3，但参数量小十倍以上；LLaMA-65B 与 Chinchilla-70B 和 PaLM-540B 具有竞争力。与此前工作不同，LLaMA 完全使用公开数据，并公开模型以便研究社区使用。作者希望发布模型能加速大语言模型研究、改善鲁棒性并缓解毒性和偏差等问题。指令微调已经显示出有希望的效果，未来还会训练更大模型和更大公开语料。
